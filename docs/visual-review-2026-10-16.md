# 화면·조작 표현 검토 · 2026-10-16

사용자의 “AI로 만든 느낌” 지적을 화면의 일관성, 장소의 용도, 인물의 식별, 행동과 결과의 연결 문제로 나눠 고쳤습니다. 자동 실행 통과와 미술·재미 평가는 구분합니다.

| 발견한 문제 | 적용한 수정 |
| --- | --- |
| 비슷한 상자 건물과 좌우 대칭 배치 | 선별한 CC0 도시·산업 모델, 높이·간격·방향을 달리한 배치, 한글 상점 간판 |
| 구역 이름만 달라 보이는 환경 | 운하의 수로·목재 통로·난간·차가운 빛, 제련소의 배관·자재 더미·따뜻한 빛 |
| 집이 바퀴 없이 떠 보임 | 바퀴를 차대 밖으로 드러내고, 지붕을 짙은 푸른색으로 정리 |
| 색만 다른 인물 | 모자·머리·장비가 다른 네 작업자, 같은 디자인의 얼굴 아이콘, 가려진 동료의 색 실루엣 |
| 지면의 물건이 계속 회전함 | 바닥에서는 정지, 회수할 때 견인 곡선, 손 높이와 맞는 운반·투척 궤적 |
| 다른 사람의 다리가 패킷마다 멈춤 | 서버 갱신 사이에도 이어지는 보행 주기와 멈출 때의 감속 |
| 위험 표시가 실제 판정과 다름 | 돌진 경로의 너비와 도착점, 폭발까지 차오르는 표시, 갑판에서도 보이는 경고 |
| 보스 UI가 보스의 입을 가림 | 체력창을 오른쪽으로 이동, 출현 배너가 사라진 뒤 별도 화면 검토 |
| 반복되는 영문 문구·반투명 카드 | 한글 제목 글꼴, 종이·작업 도구에 맞춘 UI, 거리·내구도·행동 중심의 짧은 문구 |
| 충격마다 비슷한 전자음 | 금속·나무·발소리·충격음을 구분, 위치에 따른 좌우 소리와 피크 압축 |
| 녹화가 초당 2–4장에 머묾 | 실제 브라우저별 비교, 비녹화 창의 렌더링 부담 축소, 녹화 크기와 그래픽 처리 방식 조정 |

## 참고한 방향

[Moving Out 2](https://www.team17.com/games/moving-out-2)의 생활 소품과 인물 실루엣, [Unrailed 2](https://www.unrailed-game.com/)의 이동하는 공동 목표, [Death's Door](https://www.devolverdigital.com/games/deaths-door)의 배경과 전투 표시 구분을 관찰했습니다. 참고 게임의 에셋·맵·캐릭터를 복제하지 않았습니다. 포함한 외부 모델과 음원은 Kenney CC0이며 파일별 출처와 원문 라이선스를 보존했습니다.

## 남아 있는 판단

- 작업자와 적은 직접 조립한 낮은 폴리곤 모델입니다. 손으로 만든 캐릭터 원화·리깅 수준의 세부 표현까지 갖춘 상태는 아닙니다.
- 클라우드 영상의 절전 모드는 움직임을 읽기 위해 사용했습니다. 표준·고화질 화면과 구분해 보고하며, 영상에 실제 모드와 화면 갱신 속도를 표기합니다.
- 배경은 반복 가능한 도로 구간입니다. 서로 다른 맵을 수작업으로 완성한 장기 콘텐츠 구성은 아닙니다.
- 인공 지연·동시 입력·완주·재접속 검사를 통과해도, 사람이 느끼는 타격감과 협동 재미가 입증되는 것은 아닙니다.
- 다음 단계는 친구들과 첫 플레이를 관찰하고, 설명 없이 행동을 이해하는지와 지루한 구간·불편한 조작을 기록하는 것입니다.

추가 검토에서는 일반 명중·회피·장착에 반복되던 금색 원형 효과를 줄였습니다. 목재 장애물은 나무 소리와 파편으로, 물건 회수는 별도 확인음으로 구분합니다. 보호 중에 인물 전체를 깜빡여 없애는 표현도 없애고 이름표에 표시합니다.

화면 기준 이동 검사를 추가하면서 좌우 입력과 스테레오 방향이 뒤집힌 오류를 수정했습니다. 높은 길가 건물이 적·물체·동료를 가리면 해당 건물만 잠시 옅어집니다. 반복되는 임시 배경 선율도 덜고, 주행 중 엔진과 작은 바람 소리로 정리했습니다.
