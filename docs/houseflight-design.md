# 집째로 도망 / 구현 설계

2026-10-16. 사용자가 기존 기획을 초기화하고 새 기획의 제작을 승인했으며 최대 인원을 4명으로 변경했습니다.

## 핵심

하나의 움직이는 집을 공유합니다. 끌기·던지기·장착이 운반·전투·구조를 연결합니다. 집은 자동 주행해 운전수의 역할 고정을 없앱니다.

## 규칙

- 30Hz 서버 시뮬레이션, 15Hz 상태 전송. 클라이언트는 화면 보간과 제한된 입력 예측만 수행합니다.
- 캐릭터 이동은 정규화하고 0.32초 지난 입력은 만료합니다. 갈고리·투척·회피는 서버 쿨다운과 거리 검사를 적용합니다.
- 갈고리는 선분에서 가장 가까운 유효 대상을 먼저 맞힙니다. 소유 중인 물체는 다른 참가자가 가져갈 수 없습니다.
- 투사체는 이전 위치에서 새 위치까지 선분 충돌로 판정합니다. 아군 폭발은 약한 밀림만 주며 체력을 깎지 않습니다.
- 구조는 갈고리로 즉시, 자동 복귀는 16초 뒤 내구도 8 비용입니다.
- 구역 경계는 44m, 88m, 140m입니다. 첫 두 경계의 장애물을 열면 20초 정비가 있습니다.
- 정비에서 공용 부품으로 여섯 장비를 각 2단계까지 개조할 수 있습니다. 비용 3/6. 경로는 다수결, 동률은 운하입니다.
- 운하는 빠른 적 비중, 제련소는 무거운 적 비중을 높입니다.
- 마지막 구역의 포식자를 처치하고 집이 방벽에 도달하면 승리합니다. 집 내구도 소진 또는 원정 시간 초과는 실패입니다.
- 무작위는 서버별 독립 시드에서 생성합니다. 녹화는 서버가 선택한 실제 결과로 진행합니다.

## 표현

따뜻한 오두막, 짙은 푸른색 지붕, 노란 창문, 바퀴·기관·난간·화분·천막이 있는 이동식 집입니다. 주변은 먼지의 외곽, 물안개 운하, 붉은 제련소로 전환합니다. 인물은 관절이 움직이는 직접 만든 수리공 모델입니다.

캐릭터 걷기·물체 운반·갈고리 케이블·투척 포물선·충돌 입자·바닥 위험 표시·공유 상태 HUD를 실제 게임 상태로 구동합니다. 외부 이미지를 게임 화면인 것처럼 사용하지 않습니다.

## 검증의 경계

규칙 테스트와 2·3·4인 서버 명령 플레이 샘플, 두 명의 실제 브라우저 완주, 네 명의 독립 브라우저 동시 조작을 구분합니다. 플레이 도우미는 공개 상태를 읽고 실제 입력을 결정하며 게임 규칙을 우회하지 않습니다.

영상의 스크린샷과 메타데이터는 커밋·실행 결과와 함께 보관합니다. 검증 서버를 상시 접속 서비스로 표현하지 않습니다. 보스 교전과 승리 장면은 실제로 발생한 경우에만 보고합니다.

커뮤니티 참고는 기존 대화의 2020–2026년 원문 조사에 기반합니다. 커뮤니티에서 호평받은 사례는 설계 가설이며, 이 게임의 재미를 입증하는 자료가 아닙니다.
