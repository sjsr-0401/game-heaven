# 화면 개선 기준 · 2026-10-16

사용자가 기존 화면에서 AI로 만든 듯한 인상을 지적했습니다. 색만 바꾸는 대신 장소·인물·정보 구조를 함께 고칩니다.

- [Moving Out 2 공식 화면](https://www.team17.com/games/moving-out-2): 캐릭터 실루엣, 생활 소품의 용도, 가까운 시점에서 읽히는 공간 구분을 관찰했습니다.
- [Unrailed 2 공식 소개](https://www.unrailed-game.com/): 이동하는 공통 목표 주변에 팀의 작업이 모이는 구성을 참고했습니다.
- [Death's Door 공식 페이지](https://www.devolverdigital.com/games/deaths-door): 작은 인물과 배경 사이의 명도 구분, 조용한 배경과 강한 전투 표시를 참고합니다.

## 적용

철거 골목·운하·제련소를 구분합니다. 똑같은 상자 건물 대신 Kenney의 도시·산업 모델을 선별하고, 도로·간판·작업 흔적·배치를 게임에 맞게 제작합니다. 이동식 집·작업자·적·물체·연출은 자체 코드로 제작한 요소입니다.

메뉴는 방 생성·합류·준비를 곧바로 알 수 있도록 정리합니다. 의미 없는 영문 소제목과 반복되는 감성 문구를 덜고, 한글 제목용 글꼴과 일관된 도구 아이콘을 사용합니다. 플레이 중에는 목표·내구도·동료 상태가 먼저 읽혀야 합니다.
