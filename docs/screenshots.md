# 실제 실행 캡처

[이 영상 실행](https://github.com/sjsr-0401/game-heaven/actions/runs/38868286848)의 캡처입니다. 검토 소스는 `e584cb3`이며, 실제 서버·브라우저·키보드·마우스로 진행했습니다. 영상은 실제 속도이며 2인 원정은 보스 처치와 탈출까지 완료했습니다.

절전 그래픽으로 녹화했습니다. 2인 전장 평균 12fps, 4인 평균 8fps였습니다. 검토용 자동 조작이며 사람의 재미 평가나 실제 가정용 인터넷 검증을 대신하지 않습니다.
