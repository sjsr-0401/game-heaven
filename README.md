# 게임천국 · 밤의 용병단 0.3

같은 방에서 각자의 성채를 지키는 **1–4인 개인 운빨 디펜스**입니다.
사람형 도트 용병을 소환하고 직업 시너지·유물·배치·공격 우선순위로 새벽까지 버팁니다.
참고 작품의 이미지·캐릭터·음원·맵은 사용하지 않았습니다.

## 한 판의 흐름
1. 420 G와 기본 용병 4명으로 출발합니다. 6직업을 무작위 소환합니다.
2. 같은 직업 3명으로 사격 속도·화상·연쇄·치명타 등의 고유 시너지를 켭니다.
3. 2·5·8웨이브에는 무작위 유물 3개 중 1개를 무료로 선택합니다. 미룬 선택 기회도 보존합니다.
4. 장갑병은 장갑 파괴와 마법으로, 질주병은 둔화로 대응합니다.
5. 4·8·12웨이브의 보스: 녹슨 성문지기 / 종탑의 마녀 / 새벽을 삼킨 자.
   붉은 원에서 이동하면 강타에 의한 기절을 피할 수 있습니다.
6. 보스 격파 시 140 G와 무료 승부 계약서 1장. 같은 확률로 다시 소환할 수 있습니다.
7. 12웨이브 방어 성공 또는 몬스터 누적·보스 시간 초과 시 개인 결과. 친구의 전투는 계속됩니다.

## 소환과 성장
| 등급 | 일반 40 G | 승부 120 G | 공격 배율 |
|---|---:|---:|---:|
| 일반 | 70% | 50% | ×1 |
| 희귀 | 24% | 30% | ×2.5 |
| 영웅 | 5% | 15% | ×6.5 |
| 전설 | 0.9% | 4.5% | ×17 |
| 신화 | 0.1% | 0.5% | ×42 |

직업은 각각 1/6 확률. 보장 소환·합성은 없습니다.
도박사의 동전 유물은 승부 비용을 90 G로 낮추며 확률은 바꾸지 않습니다.
골드는 이 판 안에서만 사용하는 재화입니다.
최대 용병 16명, 전원 강화 8단계. 높은 등급 용병 해고에는 확인 단계가 있습니다.

## 6직업
- 유랑 사수: 빠른 관통 사격. 3명 시 공격 속도 +25%.
- 화염 연금술사: 범위 폭발. 3명 시 3초 화상.
- 서리 검사: 둔화 검기. 3명 시 둔화된 적에 전원 피해 +25%.
- 뇌전 술사: 장갑을 무시하는 3연쇄. 3명 시 5연쇄.
- 철갑 수호자: 충격파·장갑 파괴. 3명 시 장갑 파괴 지속 연장.
- 황혼 척후병: 빠른 단검·높은 치명타. 3명 시 치명타 확률 +20%p.

## 조작
Q 일반 소환 / R 승부 소환 / W 전원 강화 / E 포격 조준 / ESC 취소.
캐릭터 클릭으로 선택, 드래그·우클릭으로 재배치, 상세 패널에서 공격 우선순위를 선택합니다.
플레이어 목록을 클릭하면 관전합니다. 관전 중 명령은 비활성화됩니다.
상단 음표 버튼으로 효과음을 켤 수 있습니다.

## 공통 뼈대와 검증
방 코드·준비·방장·재접속·방장 이관·방 격리는 모드 규칙과 분리되어 있습니다.
[새 모드 추가 안내](docs/modes.md) / [디자인·참고 자료](docs/nightwatch-design.md).

회사 환경에서는 로컬 Node/Java·개발 서버·자동 브라우저를 실행하지 않습니다.
GitHub Actions **Cloud review**가 타입 검사·빌드·규칙/방 테스트·여러 실제 추첨 시드의 한 판 시뮬레이션·두 브라우저 실제 조작 녹화·단일 HTML 재생 확인을 수행합니다.
최신 성공 실행의 `nightwatch-review` artifact에서 `review.html`을 열면 설치나 서버 없이 영상을 볼 수 있습니다.
녹화에는 게임 상태를 바꾸는 지름길·등급 고정·가짜 재화 주입을 사용하지 않습니다.
영상은 무음이며 실제 인터넷 지연이나 손 조작감 검증을 대신하지 않습니다.

## 집에서 개발
Node 22.12 이상 개인 환경에서:
```sh
git clone https://github.com/sjsr-0401/game-heaven.git
cd game-heaven
npm ci
npm run dev
```
기본 포트 3000. `npm run build` 후 `npm start`로 프로덕션 실행.
`npm test`로 규칙·방·한 판 시뮬레이션을 검사합니다.
방은 단일 서버 메모리에 보관됩니다. 서버 재시작 복구·계정·상시 공개 게임 서버 배포는 아직 구현하지 않았습니다.
