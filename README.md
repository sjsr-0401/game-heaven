# 게임천국 · 밤의 용병단

같은 방에서 친구들과 즐기는 **개인 운빨 디펜스**입니다. 사람형 도트 용병을 뽑아 각자의 성채를 지킵니다.
참고 작품의 이미지·음원·맵·캐릭터는 사용하지 않았습니다.

## 현재 구현
- 1–4인 방 코드 / 준비 / 방장 시작 / 재접속 / 방장 이관.
- 각 플레이어의 전장, 몬스터, 골드, 용병, 승패 분리. 다른 플레이어 클릭 시 관전.
- 사람형 도트 용병 4종: 유랑 사수, 화염 연금술사, 서리 검사, 뇌전 술사.
- 5등급 서버 추첨. 일반 소환 40 G: 일반 70 / 희귀 24 / 영웅 5 / 전설 0.9 / 신화 0.1%.
- 승부 소환 120 G: 일반 56 / 희귀 32 / 영웅 10 / 전설 1.8 / 신화 0.2%. 직업은 각 25%. 보장 소환·합성 없음.
- 최대 16명, 재배치·자리 교환·해고·전원 강화·지원 포격. 재화는 해당 판 안의 골드뿐입니다.
- 총격 반동, 직업별 명중 효과, 피격 반응, 치명타 숫자, 파편, 포격 흔들림. 효과음은 상단에서 직접 켤 수 있습니다.
- 10웨이브, 5·10웨이브 보스. 누적 55마리 또는 보스 시간 초과 시 해당 플레이어 패배.
- 공통 방/네트워크와 모드 규칙 분리. [새 모드 추가 안내](docs/modes.md).

## 회사 환경에서 검토
로컬 Node/Java, 개발 서버, 자동 브라우저를 실행하지 않습니다.
GitHub Actions의 **Cloud review**가 빌드·테스트·두 브라우저 실조작 녹화·MP4 인코딩·단일 HTML 재생 확인을 수행합니다.
실행 결과의 `nightwatch-review` artifact에서 `review.html`을 열면 서버 없이 영상을 볼 수 있습니다.
영상은 무음이며 실제 인터넷 지연이나 손 조작감 검증을 대신하지 않습니다.

## 집에서 개발
Node 22.12 이상이 있는 개인 환경에서:
```sh
git clone https://github.com/sjsr-0401/game-heaven.git
cd game-heaven
npm ci
npm run dev
```
기본 포트는 3000입니다. 프로덕션 실행은 `npm run build` 후 `npm start`.
`npm test`는 모드 규칙과 방 구조를 검사합니다.

## 범위
이 버전은 프로토타입입니다. 방은 단일 서버 메모리에 저장하며 서버 재시작 시 사라집니다.
클라우드 CI와 영상 제공을 구현했으며 상시 접속할 공개 게임 서버는 아직 배포하지 않았습니다.
