# 집째로 도망 · HOUSEFLIGHT

친구 2–4명이 달리는 집을 함께 지켜 마지막 방벽까지 탈출하는 협동 액션 게임입니다.

갈고리로 부품을 회수하고, 화약통을 던져 길을 뚫고, 쓰러진 동료를 끌어올립니다. 집은 자동으로 달리며, 정비소에서 공용 부품으로 장비를 개조하고 다음 경로에 투표합니다.

## 플레이

- 2–4인 온라인 협동. 방장이 방을 만들고 다섯 자리 코드를 공유합니다.
- 모두 준비하면 방장이 시작합니다. 혼자 출발하거나 다섯 번째 인원이 합류할 수 없습니다.
- 먼지의 외곽 → 두 번의 정비와 경로 선택 → 추격자 고철 포식자 → 마지막 방벽의 한 판입니다.
- 내구도가 0이 되면 실패합니다. 캐릭터는 구조하거나 16초 뒤 작은 내구도 비용으로 복귀할 수 있습니다.
- 재접속은 60초 동안 같은 캐릭터와 진행 상태를 유지합니다. 방장이 끊기면 연결된 참가자에게 방장을 넘깁니다.

| 조작 | 행동 |
| --- | --- |
| WASD / 방향키 | 카메라 기준 이동 |
| 좌클릭 유지 | 조준한 방향으로 갈고리: 회수, 공격, 동료 구조 |
| 우클릭 | 물체 투척. 빈손이면 근처 적 밀치기 |
| E | 집 가까이에서 물체 장착. 도약 발판은 현재 위치에 설치 |
| Q | 물체 내려놓기 |
| Space | 짧은 회피 |
| F | 위치 표시 |
| 상단 음표 | 직접 만든 효과음과 배경음 켜기/끄기 |
| 표준 / 고화질 / 절전 | 해상도·그림자·화면 갱신 빈도 전환 |

고철은 납품하면 공용 부품, 축전지는 가속 또는 감전 투척, 수리 가방은 집·주변 동료 회복, 화약통은 폭발 투척 또는 박격포 발사, 도약 발판은 이동 보조입니다.

## 집에서 실행

Node 24와 Git을 사용할 수 있는 개인 PC에서:

~~~sh
git clone https://github.com/sjsr-0401/game-heaven.git
cd game-heaven
npm ci
npm run build
npm start
~~~

브라우저에서 http://localhost:3000 에 접속합니다. 같은 네트워크의 친구는 서버 PC의 IP와 3000 포트를 사용합니다. 서로 다른 집에서 접속하려면 인터넷에서 접근할 수 있는 서버와 HTTPS/WSS 설정이 필요합니다. 회사 PC에서는 개발 프로그램을 실행할 필요가 없습니다.

## 클라우드 제작·영상

GitHub Actions의 **Cloud review**가 설치, TypeScript 검사, 프로덕션 빌드, 규칙·방 테스트, 실제 Chromium 키보드·마우스 조작, 게임 음향 녹음, 영상 인코딩, 단일 HTML 재생 검증을 수행합니다.

완료된 실행의 **houseflight-review** 산출물에는:
- 영상이 내장된 `review.html`
- 실제 플레이 하이라이트 `houseflight-preview.mp4`
- 편집 전 전체 녹화 `full-playthrough.mp4`
- 스크린샷과 `verification.json`

영상 HTML은 게임 서버 없이 열립니다. 첫 재생은 음소거이며 마이크를 요청하지 않습니다. 실제 인터넷 지연과 사람의 재미 평가는 자동 검증과 별개입니다.

이 저장소 자체가 항시 접속 가능한 게임 서버는 아닙니다. Actions의 검증 서버는 작업이 끝나면 종료됩니다.

## 코드

- `shared/escape.ts`: 공개 상태, 물체·개조 정의, 좌표 규칙
- `server/modes/escape.ts`: 서버가 판정하는 이동·투척·구조·진행·승패
- `src/modes/escape/scene.ts`: 직접 만든 3D 모델, 환경, 애니메이션, 조준
- `src/modes/escape/view.ts`: 입력과 HUD
- `server/rooms.ts`: 방·준비·재접속·호스트 이전
- `scripts/review.ts`: 실제 브라우저 검증·녹화
- `scripts/crew-agent.ts`: 공개 상태로 판단하는 검증용 플레이어. 게임 상태를 변경하거나 치트를 주입하지 않습니다.

이전 디펜스 코드는 기록 보존을 위해 남아 있으며 현재 기본 게임에서는 등록하지 않습니다. 새 게임은 이전 도트 리소스를 사용하지 않습니다.

집·인물·적·물체·연출은 코드로 제작하고, 배경 건물 일부는 Kenney의 CC0 모델을 사용합니다. Do Hyeon 글꼴은 SIL OFL 1.1입니다. 원문 라이선스와 파일별 출처·해시는 `public/art/`에 포함합니다. 음향은 직접 합성합니다. Three.js와 타입 패키지는 MIT 등 각 패키지 라이선스를 따릅니다. 상용 게임의 이미지·모델·음원·맵을 추출하지 않았습니다.
