# 게임천국 · Game Heaven

친구들과 방을 만들고 서로 다른 2D 모드를 즐기는 멀티플레이 게임의 첫 뼈대입니다.
첫 검증 모드는 독자적인 협동 랜덤 디펜스 **별숲 수호대**입니다. 블러드는 포함하지 않습니다.

## 브라우저로 결과 보기

GitHub **Actions → Cloud review → 완료된 실행 → Artifacts → starwood-review**에서 결과를 받습니다.

- `review.html`: 영상과 설명이 들어 있는 단일 HTML. 압축을 풀고 브라우저에서 열면 됩니다. 설치나 개발 서버가 필요 없습니다.
- `starwood-preview.mp4`: 실제 게임 화면을 자동 조작하여 녹화한 영상.
- `poster.png`: 실제 게임 스크린샷.
- `verification.json`: 해당 커밋의 자동 검증 결과.

영상은 실제 서버와 두 브라우저 클라이언트를 사용합니다. 게임 상태를 직접 바꾸는 연출은 사용하지 않습니다.
영상에서 확인할 수 있는 것은 화면 반응과 조작 흐름입니다. 실제 인터넷 지연이나 손으로 느끼는 조작감까지 보장하지는 않습니다.

## 개발 방식

코드 변경은 GitHub에서 관리하고, 빌드·테스트·녹화는 GitHub Actions의 Linux 실행 환경에서 수행합니다.
GitHub의 웹 편집기나 연결된 원격 도구로 변경할 수 있습니다. 검토용 PC에서 Node/Java나 로컬 서버를 켤 필요가 없습니다.

개인 개발 환경에서 직접 실행하려면 Node.js 22.12 이상을 설치한 뒤 다음 명령을 사용합니다.

```sh
npm ci
npm run dev
```

`http://localhost:3000`에서 방을 만듭니다. 친구들은 같은 실행 서버에 접속해야 합니다.
인터넷에서 항상 접속할 게임 서버의 상시 배포는 이 저장소의 CI 미리보기와 별도입니다.

```sh
npm test
npm run build
npm start
```

Windows PowerShell에서 npm 스크립트 정책으로 막히면 개인 환경에서만 `npm.cmd`를 사용하세요.
브라우저 녹화를 직접 실행하는 개인 환경에서는 `npx playwright install chromium` 후 서버를 켜고 `npm run review`를 실행합니다.

## 공통 뼈대와 모드

- `server/rooms.ts`: 모드와 독립적인 방 생성·입장·준비·진행·결과·방장 승계·60초 재접속.
- `shared/protocol.ts`: 버전이 있는 메시지와 공개 상태. 재접속 토큰은 공개 상태에서 제외합니다.
- `server/modes/types.ts`: 서버 모드 계약. 세션 생성·명령·고정 간격 진행·상태·종료를 정의합니다.
- `server/modes/registry.ts`: 서버에서 사용할 모드 등록.
- `src/core/transport.ts`: 연결 복구와 명령 전달.
- `src/modes/types.ts`, `src/modes/registry.ts`: 클라이언트 화면의 모드 계약과 등록.
- `server/modes/starwood.ts`, `src/modes/starwood/`: 별숲 규칙과 화면. 공통 방 코드에 디펜스 규칙을 넣지 않습니다.

자세한 추가·제거 절차와 검증 기준은 [모드 개발 안내](docs/modes.md)를 참고하세요.

## 별숲 수호대 규칙

1~4인이 같은 전장에서 각자의 수호자를 지휘합니다. 각자 3명의 수호자와 240 별조각으로 시작합니다.

- **Q / 소환**: 40 별조각. 마우스가 가리키는 빈 칸, 또는 첫 빈 칸에 소환합니다.
- **선택 / 재배치**: 클릭으로 사거리 확인. 드래그, 또는 선택 후 우클릭으로 이동합니다. 내 수호자끼리는 자리를 바꿉니다.
- **합성**: 같은 종류·등급의 내 수호자 2명을 합칩니다. 종류를 유지하며 다음 등급으로 오릅니다. 친구의 유닛은 조작하지 못합니다.
- **W / 강화**: 내 수호자 전체의 공격력을 단계당 15% 높입니다.
- **E / 별비**: 범위를 조준한 뒤 클릭하는 지원 공격. 재사용 대기시간 25초. ESC로 취소합니다.
- **작은 행운**: 일반이 9번 연속 나오면 다음 소환은 희귀 이상입니다.
- **승리**: 8번째 웨이브까지 모든 적을 처치합니다.
- **패배**: 몬스터가 65마리 쌓이거나 보스 제한 시간이 끝납니다.

일반 76%, 희귀 20%, 영웅 3.5%, 전설 0.5%입니다. 한 명당 최대 10명의 수호자를 유지합니다.
전투·추첨·자원·소유권·승패는 서버가 판정합니다.

## 현재 범위

게임은 초기 프로토타입입니다. 계정·영구 성장·상점·맵 편집기는 포함하지 않습니다.
첫 모드를 통해 공통 방 구조와 모드 분리를 검증합니다. 디플로매시 같은 다음 모드는 별도의 규칙과 화면을 구현해야 합니다.

그래픽과 수호자 이름은 코드로 직접 만든 독자적인 표현입니다.
갓타워디펜스와 메이플 운빨 디펜스는 장르 참고 대상이며, 해당 게임의 이미지·음원·맵·수치·브랜드를 가져오지 않았습니다.
